# ⭐Star-Retail-Dashboard-Powerbi

An interactive **Power BI dashboard** created to turn retail sales data into clear, actionable business insights. 📊

## 📌 Dashboard Overview

The Star Retail Dashboard provides a concise view of revenue, order activity, regional performance, and product-category trends. It is designed to help stakeholders quickly identify high-performing areas and make data-informed decisions.

## ✨ Key Metrics

| Metric | Value |
| --- | ---: |
| 💰 Total Revenue | 14.91K |
| 🛒 Average Order Value | 596.39 |
| 📦 Total Orders | 25 |

## 📊 Dashboard Features

- **Revenue by Region** 🌍 — Compare sales performance across the Southeast, Northeast, West, and Midwest.
- **Order-Tier Analysis** 📦 — Review the distribution of Low, Mid, and High order tiers.
- **Category Revenue Analysis** 🛍️ — Evaluate revenue across Fitness, Footwear, Apparel, Sports Equipment, and Accessories.
- **Regional Summary Table** 📋 — View revenue and order counts for each region in one place.
- **Date Filtering** 📅 — Use the sales-month slicer to focus analysis on selected time periods.

## 🔎 Key Insights

- The **Southeast** is the strongest-performing region by total revenue. 🏆
- **Fitness** is the highest-revenue product category. 💪
- Low-tier orders have the highest order count, indicating a strong volume of smaller purchases. 📈

## 🛠️ Tools Used

- **Microsoft Power BI** — data modeling, calculations, visualizations, and interactive reporting.
- **Retail sales dataset** — source data for revenue, order, region, category, and date analysis.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the Power BI report file (`.pbix`) in **Power BI Desktop**.
3. Refresh the data source if needed.
4. Explore the visuals and use the date slicer to filter the results.

## 🎯 Business Value

This dashboard enables retail teams to monitor performance, spot sales opportunities, understand product demand, and support more confident business decisions.
